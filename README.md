## 云服务器购买平台怎么选？先看四个硬指标

选平台本质上是在选可用性、计费灵活度、长期成本和合规支持。这四项里任何一项对不上，省几百块也补不回来。

**可用性与数据可靠性。** 各家公开承诺差别不小：阿里云标称单实例 SLA 99.975%、多可用区 99.995%；AWS 对每个 EC2 区域承诺 99.99%；西部数码标 99.95%，同时强调数据分布式存储保留 4 个副本；华为云把数据持久性写到 99.9999999%。这些数字都是厂商自己页面上的承诺，实际体验还要看你的架构有没有做多可用区部署。

**计费模式。** 华为云页面上把计费分成按需、包周期、竞价三类，这个分类在主流平台基本通用。用多久买多久选包年包月；临时跑几天选按量；能容忍被中断的离线任务，竞价实例最省钱。

**续费价。** 最容易被跳过的一项，下一节单独算。

**备案与合规。** 国内节点绑定域名必须完成 ICP 备案，香港和海外节点不需要。如果你的站还没备案，买国内机器等于先买了个不能挂域名的空壳。

## 首年便宜不等于长期便宜：下单前算清三笔账

促销页上的大字价格通常只覆盖第一个计费周期，续费会回归原价。AWS 的免费套餐页面写得很直白：Linux 1核1G 机型免费 3 个月，之后每月 32.5 元；Windows 1核2G 免费 3 个月，之后每月 130 元。国内平台的新用户特惠逻辑类似，多数限首单或首个周期。

**第一笔：续费价。** 下单前把首年价和续费价都记下来，按你打算用三年算总账。有些平台的价格优势只存在于第一年。

**第二笔：带宽和流量。** 公网成本有两种算法：固定带宽包月，或者按流量计费——西部数码页面上就把公网流量按 G 单独标价。轻量应用服务器通常送月流量包，超出后按平台规则限速或另行计费。如果你的站有图片、视频或下载，先估月流量，再决定买哪种。

**第三笔：附加项。** 快照与备份、独立 IP、高防、备案主体数量都可能另外收钱。西部数码明确写了国内非高防 IP 默认支持 1000 个域名白名单，超出按 5 元/个加收。这类条款不会出现在促销海报上，但会出现在账单里。

## 备案：买国内节点之前就要确认的事

国内节点必须完成 ICP 备案才能用域名对外提供访问，这是规定，并非某家平台自己加的门槛。香港和海外节点不需要备案，代价是访问延迟和部分行业的合规要求不同。

备案流程本身不复杂，难的是时间：首次备案要按平台指引提交资料、等待审核。如果你买机器是为了赶一个上线节点，先确认备案来不来得及；赶不上，就考虑香港节点，或者先用 IP 做测试。

## 常见问题

**云服务器购买平台哪个最便宜？**
首年价格最低的往往是中小服务商或大厂的新用户活动机型，但长期成本要看续费价。把首年价和续费价一起算，结论经常反过来。

**新用户优惠可以叠加吗？**
多数平台的活动机型限新用户首单，不能与其他优惠叠加，也不支持中途改配后保留活动价。下单前看清活动规则里的限制条款。

**买完发现不合适能退吗？**
各平台退款政策不同，有的按未使用时长比例退，有的支持短期无理由退。这条要看你下单时确认的协议，别默认所有平台一样。

**1核2G 够用吗？**
跑静态页面和低流量博客够用。带数据库、WordPress 插件多、或有并发访问，建议直接上 2 核。
